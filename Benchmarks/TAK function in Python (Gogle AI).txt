TAK function in Python (Gogle AI):

def tak(x, y, z):
    if y < x:
        return tak(
            tak(x - 1, y, z),
            tak(y - 1, z, x),
            tak(z - 1, x, y),
        )
    else:
        return z

Why it is used as a benchmark: Even for modest inputs, naive recursion triggers massive numbers of function calls—for instance, tak(18, 12, 25) generates over 76 million calls. Lazy evaluation, memoization, and mutually recursive or iterative rewrites can dramatically reduce this overhead.

In LISP:

(defun tak’ (x y z)
    (cond ((not (< y x)) z)
      (t (tak’ (tak’ (1- x) y z)
               (tak’ (1- y) z x)
               (tak’ (1- z) x y))))))
